# Hi, I'm Andrew Sarmiento

**QA Automation Engineer** building reliable software with test automation, AI-assisted testing, and a strong manual-testing foundation. Currently working on the **Banrural mobile app** (IAD & AVT projects) at Business Development Group, remote from Tuluá, Colombia.

I work at the intersection of manual testing, automation, and AI — writing test scripts, running regression cycles, and helping teams ship with confidence.

---

## What I do

- **Manual testing** — functional, regression, and exploratory on web and mobile apps. JIRA / XRAY / TestRail.
- **Test automation** — Playwright, Cypress, Selenium, KaneAI (low-code). API testing with Postman.
- **AI in QA** — integrating AI tools to speed up test case design and reduce manual cycles.
- **BDD / TDD** — Cucumber, Gherkin, CI pipelines with Jenkins.
